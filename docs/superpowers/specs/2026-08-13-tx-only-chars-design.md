# 送信専用符号の拡張 設計書

作成日: 2026-08-13

## 1. 目的

モールス符号としては規定があるのに、この語彙に入っていないために「送信できない
文字」になっている記号を送れるようにする。**受信語彙 (NN トークン集合) には
一切触れない。** トークン ID を動かすと学習済みモデルが無意味になるためで、
送信は NN を通らないから送信側だけで完結できる。

きっかけ: 運用者が `!"#$%&'~|+*<>_` の扱いを質問し、「モールスコードで変換
できるものは全て送信できる扱いにしてほしい」と要望した (2026-08-13)。

## 2. 追加する符号

出典は ITU-R M.1677 と無線局運用規則 別表第一号。**実装前に原典と照合すること**
(実装を見て参照表を書いてはいけない — `・-・-・・` 誤記事件の教訓)。

### 欧文 (文字として入力)

| 入力 | 符号 |
|---|---|
| `:` | `---・・・` |
| `'` | `・----・` |
| `"` | `・-・・-・` |
| `(` | `-・--・` |
| `)` | `-・--・-` |
| `×` (U+00D7) | `-・・-` (X と同符号。規則上の乗算記号) |

### 和文 (マーカーとして入力)

| 入力 | 符号 | 意味 |
|---|---|---|
| `{KAKKO}` | `-・--・-` | 下向括弧 `「` |
| `{TOJI}` | `・-・・-・` | 上向括弧 `」` |

和文の括弧を文字 `「` `」` で入力させないのは、既存の 2 つの意味と衝突するため:
`「…」` は**欧文区間マーカー**であり、`」` 単独は**段落の別名**である。
どちらの既存動作も**変えない** (運用者確認済み 2026-08-13)。

### 対象外 (理由つき)

- `! # $ % & ; _ | ~ < >` — 国際符号に単独の割り当てが無い。`%` は規則上
  `0/0` と 3 文字で書く決まり
- `=` `+` `@` `?` `/` `.` `,` `-` — 既に送れる

## 3. アーキテクチャ

### 置き場所 (単一ソース原則の維持)

`src/tokens/morse_tokens.py` に送信専用の補助表を追加する:

```python
TX_ONLY_EUROPEAN_CHAR_TO_CODE: Final[dict[str, str]] = {...}   # : ' " ( ) ×
TX_ONLY_MARKERS: Final[dict[str, str]] = {"{KAKKO}": "-・--・-", "{TOJI}": "・-・・-・"}
```

`text_to_codes(text, mode, emit_word_breaks=True, include_tx_only=False)` に
フラグを足す。**既定 False — 合成器・学習・既存呼び出しは今と完全に同じ挙動。**
True のとき欧文表に TX_ONLY_EUROPEAN を、マーカー表に TX_ONLY_MARKERS を
マージして解釈する。

### 送信側の変更

- `src/tx/encoder.py`: `text_to_codes(..., include_tx_only=True)` で呼ぶ。
  `find_unsendable` の判定表・マーカー正規表現にも TX_ONLY を合流させる
- `_JAPANESE_TX_CHARS` は従来どおり (`」` = 段落の別名は不変)。和文モードで
  送信可能になる新文字は**無い** (括弧はマーカー経由のみ)
- 欧文モードの新規文字は `: ' " ( ) ×`。小文字化の影響なし (記号のため)

### 触ってはいけないもの (歯止め)

- `EUROPEAN_TABLE` / `JAPANESE_TABLE` / `_build_unified_tokens` — トークン ID の源
- `SPECIAL_INPUT_MARKERS` — **合成器から見える。** ここに `{KAKKO}` を足すと
  語彙に無い符号がラベル生成へ流れ、`TOKEN_TO_ID` の KeyError で学習が落ちる
- 受信側の変換表 (`converter.py`) と `web/src/generated/tokens.ts`

## 4. 受信の非対称性

追加した符号は受信語彙に無いので、**自分は送れるが、相手から受けたときは `?`
になる** (TABLE_MISS)。これは仕様であり、解消は再学習の機会にトークン追加と
セットで行う。USAGE に明記する。
