cw-decoder 取扱説明書

モールス信号を耳で追わずに、画面で読むためのソフトです。 受信した音を文字にして、必要なら日本語として整え、返信を打つところまでを 1 つの画面で行います。

このソフトができること

マイクやライン入力から入った CW の音を、深層学習のモデルが符号の列として読み取り、 それを欧文表・和文表で文字に直して画面に出します。 読み取りは受信しながら進むので、交信の途中でも読めます。

  • 欧文・和文の両方を読みます。どちらの符号が来ているかを自動で判断させることもできます。
  • 読めなかった文字を隠しません。 自信がなかった箇所は _ で残します （なぜ隠さないのか）。
  • 語彙で崩れを直します。 符号の乱れで崩れた語を、モールス符号としての近さを見て直します （辞書補正）。
  • LLM で日本語に清書できます。 ローカルの Ollama でも、クラウドの API でも使えます （LLM 清書）。
  • 返信を打てます。 無線機を繋いだ別の PC に LAN 越しで打鍵させます （送信する）。
読み取りの精度について

完璧には読めません。実際の受信音で測ると、欧文でおよそ 16%、和文でおよそ 32% の文字が間違います。 ただしこれは熟練者が耳で読んだときと大きくは変わらない水準です （状態の悪い信号で、人が 28.6%、モデルが 34.9% という実測があります）。 「1 文字も間違えずに読む道具」ではなく「意味を取るための道具」だとお考えください。 辞書補正と LLM 清書は、まさにその「意味を取る」ための仕掛けです。

まず動かしてみる

  1. アプリを起動します。導入がまだなら INSTALL.md を先にご覧ください。

  2. 画面いちばん上のコンボボックスで、音の入り口（マイク／ライン入力）を選びます。

  3. 右隣の モード: で 欧文 和文 自動 から選びます。 迷ったら 自動 で構いません。

  4. ● 開始 を押します。音の取り込みが始まり、レベルメータが振れ、スペクトルが流れ出します。

  5. ● デコード開始 を押します。ここから文字が出ます。

    取り込みと読み取りが別のボタンに分かれているのは、先にレベルとスケルチを合わせてから 読み始められるようにするためです。

止めるときは ■ 停止 です。本文を消したいときは クリア を押します。

全体の流れ

音が文字になるまでに、いくつかの段を通ります。どこで何が起きているかを知っておくと、 結果がおかしいときにどこを疑えばよいかが分かります。

段すること調整する場所
1. 取り込み 音声デバイスから音を受け取り、帯域通過フィルタで目的の音だけ残す 主画面のレベルメータ／設定の入力タブ
2. 読み取り モデルが符号のトークン列を出す 設定のデコードタブ
3. 確定 後から変わらない位置まで来た文字を確定させる 設定の確定タブ
4. 文字化 符号を欧文表・和文表で文字に直す。自信のない箇所は _ にする 設定のデコードタブ（確信度の閾値）
5. 辞書補正 崩れた語を語彙に寄せて直す 設定の補正タブ
6. LLM 清書 全体を読み直したうえで、日本語として整える 設定の清書タブ

1〜5 は受信しながら進みます。6 だけは まとめて清書 を押したとき （または自動清書の間隔がきたとき）に走ります。

どこから読むか

  • 画面の説明 主画面のボタン、設定画面の 6 つのタブ、別ウィンドウで開く画面。
  • 受信する モードの選び方、レベルとスケルチ、帯域通過フィルタ、録音、WAV の後読み。
  • 読み取りと補正 _ と ? の違い、確定の仕組み、辞書補正、語彙の増やし方。
  • LLM 清書 Ollama とクラウド API の設定、自動清書、赤字の意味。
  • 送信する 打鍵側 PC への接続、返信の型、経歴、送れる文字。
  • 設定項目一覧 6 タブすべての項目、既定値、変えたときの効き方。
  • うまくいかないとき 文字が出ない、化ける、遅い、繋がらない。

安全のためのお願い

電波が出ます

送信の機能は、LAN の先にある PC を通じて実際に無線機の電鍵を押します。 初めて繋ぐときは、必ずアンテナの代わりにダミーロードを付けた状態で確かめてください。 手順は「初めて繋ぐとき」に書いてあります。
