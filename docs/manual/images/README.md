# 取扱説明書に使う画面イメージ

このフォルダに PNG を置くと、取扱説明書の該当箇所に表示されます。
まだ無いものは、破線の枠に「どの画像がここに入るか」が出ています。

**公開リポジトリに入ります。** 経歴・送信の画面には自局の情報が写るので、
公開してよい値かどうかを確認してから撮ってください。

| ファイル名 | 撮る状態 | 使う場所 |
|---|---|---|
| `main-idle.png` | 起動直後・停止中 | 画面の説明 |
| `main-decoding.png` | 受信＋デコード中。本文が数行たまり、スペクトルに符号が見えていて、レベルメータが振れている | 画面の説明（いちばん目立つ場所） |
| `main-refined.png` | LLM 清書の結果が出ている（黒＋赤の文が入った状態） | LLM 清書 |
| `spectrogram-sliders.png` | スペクトル部分の拡大。下の「濃さ」「幅」スライダが読める大きさで | 画面の説明 / 受信する |
| `settings-input.png` | 設定画面「入力」タブ | 画面の説明 / 設定項目一覧 |
| `settings-decode.png` | 設定画面「デコード」タブ | 同上 |
| `settings-commit.png` | 設定画面「確定」タブ | 同上 |
| `settings-correct.png` | 設定画面「補正」タブ | 同上 |
| `settings-refine.png` | 設定画面「清書」タブ | 同上 |
| `settings-display.png` | 設定画面「表示」タブ | 同上 |
| `tx-dialog.png` | 送信画面。日本語欄に例文を入れて `確認` を押した後（「送信される文字」が埋まっている状態） | 送信する |
| `profile-dialog.png` | 経歴の編集画面。値が入った状態 | 送信する |
| `template-dialog.png` | 返信の型の編集画面 | 送信する |

## 撮り方

- ウィンドウごと撮ってください（枠が入って構いません）。
- 等倍で。縮小すると設定画面の文字が読めなくなります。
- Windows なら対象のウィンドウを選んで <kbd>Alt</kbd> + <kbd>PrintScreen</kbd>、
  または <kbd>Win</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd> で範囲を選べます。
