# cw-decoder — AIモールス信号デコーダ

機械学習(深層学習)ベースのモールス信号(CW)リアルタイムデコーダ。手送り電鍵の揺らぎ・QSB(フェージング)・QRM(混信)・QRN(空電)に対してロバストなHF帯(主に7MHz) CW運用向けのデコーダ。

CNN + BiLSTM + CTC モデルで音声から符号トークン列を取り出し、決定論的な変換表で欧文/和文テキストにデコードします。学習済みモデル(`models/full/best_infer.pt`, 約17MB)を同梱しており、**入手してすぐ使えます**。

### 送信もできます（Phase 11）

受信だけでなく、**無線機を繋いだ別の PC に LAN 越しで打鍵させられます**。
電鍵線と PTT を DTR/RTS で駆動し、**LAN が止まれば打鍵も止まります**（心綱）。
送信前に必ず `[確認]` を通す関門があり、確認していない文字列は送れません。

詳しくは [取扱説明書 §12](./docs/USAGE.md) を参照してください。
**電波を出す機能です。免許の範囲内で使用してください。**

## 既知の制限

| 制限 | 内容 |
|---|---|
| **先頭の幻覚** | 音の立ち上がりでモデルが余計な符号を出します。デコード前に 0.3 秒の無音を足して減らしていますが、消えてはいません |
| **自動モードのホレ検出** | 欧文の前置き（`JA1ABC DE JH0ILL …`）に続くホレをモデルが認識できません。実測で純和文なら検出率 100%、実運用の形では 0%。**和文専用符号を見たら切り替える経路が働くので、実害は「ホレの文字が出ない」ことに留まります。** 学習データに実運用の形が入っていないことが原因で、解消には再学習が要ります |
| **語間** | 実録音では語の切れ目が落ちやすく、`CQDE` のように繋がることがあります。辞書補正（既定 ON）が主にここを直します |
| **鍵括弧の符号** | `「` `」` の本来の符号（`-・--・-` / `・-・・-・`）は符号トークン集合に入れていません。追加するとトークン番号がずれて再学習が必要になるためです |

## アーキテクチャ方針

「音→符号」と「符号→文字」を分離する:

```
音声入力 → [前処理: メルスペクトログラム]
        → [NNモデル: CNN + BiLSTM + CTC]
        → 符号トークン列(全モード統合)
        → [変換表: 欧文表 / 和文表 / 自動]
        → 表示テキスト
```

NNは音声から**符号トークン列**を取り出すことに専念し、文字割当(欧文/和文)は決定論的変換表で行います。この分離により、新しい文字表示要件は**変換表の修正だけ**で対応でき、モデル再学習が不要になります。

## クイックスタート

詳細は [インストールマニュアル](./docs/INSTALL.md) を参照してください。

```powershell
# 1. 仮想環境を作って有効化
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# 2. インストール
pip install -e .

# 3. 受信機なしで動作確認（サンプル音声をデコード, TER 0% を確認）
python scripts/generate_samples.py --out data/samples --european 12 --japanese 12 --seed 42
python scripts/decode_demo_samples.py --ckpt models/full/best_infer.pt --dir data/samples

# 4. アプリを起動
python scripts/run_app.py --ckpt models/full/best_infer.pt
```

アプリの操作方法は [取扱説明書](./docs/USAGE.md) を参照してください。

受信機を繋いだ PC と処理する PC が別の場合は、受信機側で送信スクリプトを動かします。

```powershell
# 受信機を繋いだ PC で（深層学習のライブラリは不要）
python scripts/audio_send.py --list      # 入力デバイス番号を調べる
python scripts/audio_send.py --device 13

# 処理する PC で
python scripts/run_app.py --ckpt models/full/best_infer.pt --net-source 192.168.1.20
```

## テスト実行（開発者向け）

```powershell
pip install -e .[dev]
pytest -v
```

主要テスト:

- `tests/test_tokens.py` — 符号表と e-Gov「無線局運用規則 別表第一号」との照合
- `tests/test_converter.py` — トークン列 → 文字列変換 (濁点合成・確信度閾値含む)
- `tests/test_synth_*.py` — 合成器の波形・ノイズ・データセット動作
